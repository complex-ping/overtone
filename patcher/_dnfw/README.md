# _dnfw

The parts of [dnfw](https://github.com/angellinares/dn2_firmware_explore) (angellinares; AGPL-3.0-or-later, see LICENSE)
that the patcher needs to read, rebuild and seal a Digitone II OS file: the SysEx transport, the ELE3 container, the
aPLib packer and unpacker, and the integrity fields. Copied unchanged from `src/dnfw/` at commit
`9104eac817746e655f606372d272766fe3935dec` (2026-09-27); only the package's name differs.
