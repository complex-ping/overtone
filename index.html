Overtone builder Overtone

Overtone is custom firmware for the Elektron Digitone II. This page makes it on your computer from Elektron's own OS 1.12 file. Then you send it to the Digitone with Elektron Transfer, like any OS update.

What's in Overtone · Project page

1

Get Elektron's OS 1.12

On Elektron's Digitone II download page, download Digitone II OS 1.12. You get Digitone_II_OS1.12_dist.zip.

2

Drop it here

The .zip as you downloaded it, or the Digitone_II_OS1.12.syx inside it.

3

Make Overtone

Takes under a minute. Keep this tab open.

Starting…
4

Send it to the Digitone

  1. Connect the Digitone II to the computer by USB, switch it on and open Elektron Transfer.
  2. Drag the saved file onto Transfer.
  3. Press YES on the Digitone when it asks, then wait until it has restarted.
Going back, updating, and if it doesn't start
  • Back to Elektron's OS: send Digitone_II_OS1.12.syx (inside Elektron's .zip) with Transfer the same way.
  • A newer Overtone: make it here and send it the same way.
  • If the Digitone doesn't start: hold FUNC while switching it on, press TRIG 4 (OS UPGRADE), and send Digitone_II_OS1.12.syx from Transfer's LEGACY OS UPGRADE mode over a DIN MIDI cable (USB doesn't work in this menu; it takes about 15 minutes).
  • More in the project's README.
